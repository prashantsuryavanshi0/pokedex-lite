# Pokedex Lite

This is a simple React project where I built a Pokedex app using the PokéAPI.
The goal was to create a clean and responsive UI where users can explore Pokémon easily.

---

## Features

- Fetch Pokémon data from API
- Search Pokémon by name
- Filter Pokémon by type
- Pagination (Next / Prev buttons)
- Mark Pokémon as favorites ❤️
- Favorites are saved using localStorage
- Click on a Pokémon to see details (HP, Attack)
- Responsive design (works on mobile and desktop)

---

## Tech Used

- React (Vite)
- Tailwind CSS
- Axios
- Framer Motion (for small animations)

---

## How to Run

1. Clone the repo:
   git clone https://github.com/YOUR-USERNAME/pokedex-lite.git

2. Go inside folder:
   cd pokedex-lite

3. Install dependencies:
   npm install

4. Run the project:
   npm run dev
